## 1. 任务场景

用户把 ≥3 块积木摆在拾取区（沿用阶段 2 的摆法与间距），系统逐块抓住并**叠到基准垫
中心格**上，形成直塔：

- **3 块起步，5 块达标**；每层同一格、同一朝向（格线方向）。
- **塔基**：基准垫中心格 `idx4`（格心以当轮 `grid.json` 为准）。
- **块**：同一批方块，**真高 29.5 mm**（用户多次实测；细微偏差对本实验无影响）。
- **拾取区**：沿用 `[0.25, 0.575, 0.17, 0.42] m`（base 系），块间距仍 ≥60 mm。
- **判分（三方冗余）**：
  1. **逐层机测**——每层放好、夹爪撤走后**立即**从两个高位视点各抓 ≥3 帧，
     量当前塔顶的中心 / yaw / 顶面高度；这就是该层指标的**唯一来源**；
  2. **终态复测**——最上层放完静置 10 s 后再测，回答「顶层有没有动、塔有没有塌」；
  3. **人眼复核**——看台面与判分图，未填复核意见的层不得判 `ok`。
- 不涉及：颜色归位、多塔、动态目标、roll/pitch 六自由度、夹爪速度环。

## 2. 与阶段 2 的技术与设备差异

| 维度 | 阶段 2 | 阶段 3 |
|---|---|---|
| 放置面 | 固定台面（`TABLE_PLANE_Z=0`） | **上一层实测顶面**（第 1 层为垫面） |
| 新增被测量 | xy / yaw | **z 增量**、层间相对 xy/yaw、释放扰动 |
| 测量位姿 | 固定 `stage2close` 对 | **高度跟踪对**：巡检位随塔高上移，相机—塔顶距离恒定 |
| 碰撞模型 | 肘 / 腕 1 / 裸指尖对台面 | 再加**持块 8 角包络** + **塔体 box** |
| 释放控制 | 开口宽度 / 停留时间 | 同一组参数，但**入口扫参选重复性最好的组合** |
| 感知 | 单帧顶面 | **只看得见最上层**（俯视遮挡），逐层指标靠「当层立即测」 |
| 不变 | 腕部 D435i、AG-95、UR5、垫子与 `grid.json`、SSH+文件接缝、执行闸门 | 同左 |

**关键技术事实**（决定上述设计，不许在实现里绕开）：

- 竖直俯视下塔只有**最上层**顶面可见；下层被上块压住。终态**不能**复测下层，
  下层稳定性只能由「顶层没动 + 塔高没塌 + 人眼」间接判断。
- `stage2high`（相机 ~522 mm）在阶段 2 已被判「**顶面碎、yaw 不可信**」
  （`precision_plan.py` 注释，2026-10-27 B2）。堆叠的测量位姿不能是固定高位，
  也不能是固定 `stage2close`（5 层时相机距塔顶仅 ~214 mm，逼近 D435i 近限）。
- `place_z = 表面高度 + grasp_z + 5 mm`，而 `grasp_z` 由**拾取时同一块的高度
  `wz`** 决定 ⇒ 放置计划里的块高与抓取计划里的块高必须**同源**；混用名义 29.5
  与实测值会把块高偏置以 `(block_h − wz)` 叠进放置高度。
- 垫面不是台面：塔位第 1 层的放置面是 `grid.json` 的 `T_base_pad[2,3]`
  （本例 2.0 mm），标定塔位 z 偏差时必须扣除它，否则会把垫厚记成读数偏差。

## 4. 出口判据

### 4.1 主命题（决定达标与否）

**开环 xy/yaw + 逐层 z 测量/标定**能把 3 块塔稳定做到 5 块塔。
「开环」指 **xy/yaw 的期望目标固定（主组 = 格心）、不追着歪塔走**；z 的表面高度
仍用当层实测。

**2026-11-02 用户拍板追加「轮内自适应放置偏置补偿」**（选项 b；台账第二百零六轮）：
每层放好后记 `b̂ = 实测块顶中心 − **命令**目标`，第 k 层的**命令**目标 =
`期望目标 − b̂`（b̂ 取「先验种子 + 本轮已测各层」的均值）。`|b̂| > 15 mm`
**按失败停轮**，不当偏置用（那是块掉了 / 没抓住 / 塔被撞了）。

- **先验种子是必需的，不是可选项**：第 1 层没有本轮历史；若它不补、第 2 层补满
  b̂，第 1↔2 层之间就凭空多一个 ≈|b̂| 的**折角**，判分看的正是相对对中。
  种子来源优先级：`--bias-seed bx,by` > `<run-dir>/bias_estimate.json`（上一轮
  攒下的，每轮结束自动更新）> 无（此时第 1 层不补，本轮结果要注明）。
- 这**不是** xy 闭环：期望目标从不因实测塔位改变，绝对格心偏差照旧判分与报告。
- 补偿的是**块 ↔ 夹爪**之间的系统性 offset（机放实测系统性偏向 base 的
  (−x, −y)、3–4 mm、方向稳定）。它不在「目标 → 臂」这条链上，
  **闭环组也消不掉它** —— 闭环把下一层目标改成上一层实测中心，下一层照样再偏。
- `--bias-comp none` 逐字节复现未补偿语义，只用于对照，**不作主组**。
- 主组与闭环组都开着补偿：两组的唯一差别仍是「期望目标取格心还是取上一层实测」。

| 指标 | 判据 | 怎么量 |
|---|---|---|
| **z 增量** | 每层顶面升高 **29.5 ± 2 mm**，**从第 2 层起算** | `top_k − top_{k−1}`；第 1 层只作基准，其绝对顶高只报告 |
| **相对对中** | 上块中心相对下块中心 **≤ 5 mm** | 本层当层实测中心 − 下层当层实测中心 |
| **相对 yaw** | 上块相对下块 **≤ 5°**（mod 90°） | 本层当层实测 yaw − 下层当层实测 yaw |
| **稳定性** | 最上层静置 **10 s** 后：Δxy ≤ 2 mm、Δyaw ≤ 2°、Δz ≤ 2 mm | 终态复测 vs 该层放好瞬间 |
| **塔不倒** | 全程无倾倒、无层间明显错位 | 机测 + 人眼复核 |

**绝对格心偏差**（本层中心 − 中心格心）**一并报告但不单独判红**：塔是否成立由
「相对下层」决定，绝对偏差用来解释塔整体漂移。

### 4.2 测量协议（逐层什么能量、什么不能量）

1. **立即测**：每层松手、撤退后**立即**用高度跟踪位姿对测该层顶面；测不到即
   `measured_missing`，该轮停在这里，**不赌终态能补**。
2. **逐层来源**：第 1..N 层的绝对中心 / yaw / 顶高，一律取「该层放好瞬间」的记录，
   标 `metric_source: "immediate"`；逐层判据只读 immediate。
3. **相对量**：本层 immediate − 下层 immediate。两次测量噪声相加，报告里注明
   （单次 σ 由入口实验 1 给出）。
4. **终态只复测最上层**：回答 10 s 稳定性、塔高是否变、顶层是否偏移、塔是否塌；
   **不允许**从终态反推或插值下层指标。可选 `ledge` 检查（下层向外凸出的粗错位）
   只作诊断，不产生下层中心 / yaw。
5. **多姿态一致性门**：两视点差 **≤6° / ≤10 mm**（沿用阶段 2）；不过 ⇒
   `person_review`，不进机判。**yaw 这一维（6° 与逐层相对 yaw）一律走彩色掩码
   估计器**，深度 `yaw_rect` 只作报告（2026-11-01 用户拍板：同批 15 次上两套
   数据逐次相关 r=0.897、颜色 ≈ 0.70 × 深度，深度法把偏差放大约 1.43 倍，
   组内散差 6.5–15.5°，当判据会把合格放置判红）。彩色 yaw 缺失 ⇒
   `person_review`，**不拿深度顶替**。
6. **人眼复核**：未填复核意见 ⇒ 不得判 `ok`。

### 4.3 轮次与达标

- **主组（开环 xy/yaw）**：3 块 × **3 轮** + 5 块 × **3 轮**；默认
  `--bias-comp adaptive`（轮内自适应补偿，见 §4.1）。
- 每轮逐层全过（§4.1 表）才算该轮达标；**任一层超阈值、任一层 `person_review`、
  或塔倒 = 该轮不达标**。
- 达标轮数：3 块组 3 轮 + 5 块组 3 轮，全部达标即阶段出口。
- **闭环组（对照，只报告）**：第 k≥2 层的 xy/yaw 目标改为第 k−1 层实测塔顶中心 / yaw；
  **1×3 + 1×5**，单独报告成功率，**不参与达标**。同样开轮内偏置补偿（§4.1）。
- **eye-in-hand 组（第二对照，条件触发）**：入口第 3 项通过才做，最多 1×5；
  只报告成功率与修正量，不参与达标。不通过 ⇒ 记录「本阶段不做」。
  **2026-11-02 落地（台账第二百零七轮）**：每层拆成「抓 → 载运」与「载运 → 放」
  两段。段 A 走到 `to_slot`（carry 高度）停住，夹着块抓 ≥3 帧，**按期望顶高**
  （上一层实测顶 ±6 mm）认塔顶 —— 手里那块比塔顶高 74–123 mm，按「最高簇」取会
  量到它；量到后把**期望目标**改为这次实测的中心 / 彩色 yaw，再用 `build_place`
  重规划段 B。第 1 层没有塔顶可量（垫面 2 mm < `MIN_H_MM`），与闭环组一样取格心。
  `|修正| > 10 mm`、量不到、彩色 yaw 判不了 ⇒ **停轮**（fail-closed，不拿旧目标硬放）。
  修正量 = carry 实测 − 上一层当层实测（即它与闭环组目标之差），逐层落盘。

## 5. 明确不做

- 颜色归位（阶段 2 已验）、任意类别 / 非方块、多塔、动态目标；
- roll/pitch 六自由度（只做竖直直塔 + yaw）；
- 夹爪速度环（`0x0104` 已实测失效：五档速度都是 0.35–0.36 s）；
- 超过 5 层、悬臂 / 交错 / 斜面等塔型；
- 抓取顺序优化、多块同抓、掉块自动重抓（失败即停，交给人）；
- 轮间自动复位（人把块摆回拾取区、清空塔）；
- 在线闭环作为达标判据（闭环只报告）；
- 俯视相机回系统（漂移不可控，沿用阶段 2 决定）。

## 6. 失败模式表

| 失败模式 | 现有缓解 | 处置 |
|---|---|---|
| z 读数偏高 → 块悬空落下；偏低 → 压块 | 入口 z 标定 + 每层立即实测 + 拾取/放置同源 `wz` | 标定重复性 >2 mm 不开主轮；层间 z 增量超 2 mm 停轮 |
| 释放扰动 → 上层偏移 | 入口扫参（开口 × 停留）+ 停留时间 | 选重复性最好的组合；超阈值停轮 |
| 塔顶被夹爪 / 持块遮挡 | 高度跟踪位姿对 + 多帧 | 遮挡实验决定 eye-in-hand 做不做；下层指标只靠当层记录 |
| 第 5 层 IK 进入坏分支 / 软限位 | 整链选支 + 塔体碰撞护栏 | 计划期就拒（exit 2），不执行 |
| 持块横移撞塔 | 持块 8 角包络 + 塔体 box（上一层实测中心 ± 半边长 +2 mm） | 任一采样点入箱即不写计划 |
| 程序自停（反向 socket 超时） | 执行器 fail-closed（PLAYING / JTC / robot_mode 三闸） | 停轮、人工判读示教器日志；**堆叠不自动续跑**（块可能还在爪里 / 半放） |
| 块在指间转动 | 阶段 2 已证几何臂可控 | 每层立即测 yaw，超 5° 停轮 |
| 塔整体漂移（追着歪塔叠） | 主组**期望**目标固定为格心（实测塔位不改它）；轮内只补偿块↔夹爪偏置（§4.1） | 绝对格心偏差一并报告；闭环组只报告不达标 |
| 测量位姿在 5 层仍不可用 | D 三档入口实测 | 换 D 或退回分层自适应位姿；仍不行 ⇒ 记录并降级为 3 块出口，由用户拍板 |

## 7. 悬案

1. ~~**释放重复性的数值闸门**~~ —— **2026-11-01 已拍板**：中位 + 3σ，
   Δxy ≤ 7.0 mm / Δz ≤ 2.9 mm，已写进 §3 第 2 项。**yaw 不设可过门**：
   散布（σ 5.14°）是真实的释放转动而非测量噪声，改由 §3 第 5 项矫正解决。
2. **5 层时高度跟踪位姿的实际 σ**——入口实验 1 回答；σ 过大则调整 `D` 或加帧。
3. **eye-in-hand 是否可行**——入口实验 3 回答；不做就明确关闭。
4. **z 是否需要闭环修正**——用户：先看主组实测误差是否明显；明显再议，不预设。
5. **z 偏差随位置变化**——历史同块换位读数差可达 ~8 mm；当前只用常数 + 分区记账，
   同一塔位残差 >2 mm 时再升级线性 / 非线性模型（用户已定升级路径）。
6. **第 1 层放置面**——本契约取 `grid.json` 的 `T_base_pad[2,3]`；若入口测出垫面
   高度与该值差 >2 mm，先修 `grid.json` 再开主轮。
7. **彩色 yaw 的共同系统性偏差**——两套估计器相关 r=0.897，足以排除随机噪声，
   但两者看的是同一块，**共同**的系统性偏差排除不掉。方形块上最小外接矩形本身
   是有条件的（90° 周期）。要彻底定论需一个已知朝向的真值（如块卡进已知角度的
   定位槽）。在此之前，彩色 yaw 的**绝对**准确度按 ±1–2° 看待，相对量不受影响。
