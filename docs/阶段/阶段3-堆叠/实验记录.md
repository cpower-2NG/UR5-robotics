## 五、这个阶段留下的机制结论

1. **层间误差 ≡ 真实偏置离先验的距离**：`previous` 口径下，`xy_rel_k = b̂_k − b̂`，命令项与上一层
   测量噪声相消；把 b̂ 钉死（`fixed`）比轮内自适应方差小一半。绝对位置变成随机游走，`xy_abs` 只报告。
2. **b̂ 必须取矫正前**：混入 nudge 拖拽会让估计逐层漂（round-08 失败机制，第 249 轮）。
3. **nudge 有物理副作用**：夹/扭/松自身沿 −x 侧推 1–5 mm（世界系固定矢量 E，第 189 轮）；
   它治 yaw 可靠、治 xy 不可靠；补偿它反而把 b̂ 教歪。
4. **测量必须先于叠放可信**：两视点一致性门 10→5 mm（第 240 轮）、尺寸闸门、截断闸门、
   彩色掩码 HSV 判据（第 199–201 轮）——环环都是被真机坏帧逼出来的。
5. **观测手段会扰动被测系统**：轨迹执行期间挂 1 Hz `programState` 轮询（每次都新建 ROS 2 节点）
   会造成反向接口断开；停掉后 16 分 42 秒 / 62 航点零断开（`经验总结` §4.4，第 257 轮）。
6. **拆塔回位是轮间复位的唯一方式**：机器人自己做（契约 §4.3）；`obstacles_for_slot` 把窄顶面
   被跳过的小块并入选位，2026-11-06 真机首次触发（第 259 轮），未改变选位。
