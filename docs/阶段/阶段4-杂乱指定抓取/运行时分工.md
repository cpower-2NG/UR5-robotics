## 2. 硬约束（改之前先读）

1. **轮内不拉 burst**：五组 burst（跑前 pick/pad、跑后 pick/free/pad）只在**归档段**、
   即整轮结束且令牌窗口之外才拉回。
2. **fail-closed，不回退**：板上分析失败 = 停轮；没有「本机重算」的代码路径。
   `--analysis local` 只给离线排练，必须配 `--dry-run`。
3. **轮内只回传 KB 级 JSON**（解垫 / 真值 / 彩色 / 探针 / 计划）。
4. **SSH 连接复用**：`precision_round.ssh_opts()` 是唯一出处（ssh / scp / `rsync -e`
   共用）。不复用时一轮约 30 次冷连接 ≈ 11 s，全烧在 600 s 令牌窗口里。
5. **板子仍是独立检出**：全树 rsync 到 `~/stage4-entry`；`scripts/` 与 `config/`
   拷过去即生效，**只有 `ros2_ws/` 要 `colcon build`**。

## 3. 为什么不在本机算

- 用户定调（2026-11-12）：**本机不承担运行时任务**。开发机睡眠 / 断网 / WSL 抖动会直接
  打断一轮；轮内拉图（0.33–1.4 MB/s）本身就是令牌窗口里的净浪费。
- 板端实测代价：解垫 3.1 s、20 帧真值 7.8 s（jobs 6）、彩色 <1 s/块 —— 多花约 2 s
  换掉轮内 40 MB 级搬运。线程钉（`OMP/OPENBLAS/MKL_NUM_THREADS=1`）必须在
  `import numpy` **之前**，否则 OpenBLAS 超订把 6 核跑成 1 核。
- 双端比对（同一 burst、同一份代码，台账第 323 轮）：truth 105 字段仅 6 处浮点差
  （≤6.3e-7°）、pad 9 处 ≤1e-12 相对差、colour 74 字段逐位相同 ⇒ 板端入口不引入
  任何计算分歧，它只是参数装配层。

## 7. 坐标系与单位速查（最常踩的钉在这里；证据在各阶段技术文档与台账）

- **base ↔ base_link**：示教器读数的 `base` 与 URDF/MoveIt 的 `base_link` 差绕 z
  180°。任何外参/坐标**必须标父系**。
- **腕部链**：`base_link → … → tool0 → camera_link → camera_color_optical_frame`。
  手眼 `tool0→camera_link`（2026-10-24 标定，5 位姿 1.13 mm / 0.31°）由板上
  `wrist_tf_publish.py` 发布——**起栈后要单独核它在跑**（第 315 轮：缺它 burst
  全废）；`camera_link→optical` 的 15 mm 是 D435i 固定内偏，**不是**
  `STAGE3_CAMERA_OFFSET`（那是另一条边）。
- **单位**：Python 侧一律**毫米**；米只在 ROS msg / URDF / 计划 JSON v2（显式标注）。
  yaw 一律**度**，弧度只许在换算中途存在——第 314 轮曾按弧度读度打出 5085°。
- **yaw 折角**：块 90° 对称 ⇒ 块间比较用 mod 90；放置 ±180° 等价走
  `--place-yaw-equiv180`；折叠 / 折叠+180 是唯一真等价两支（不折叠变体是数学
  空转，2026-11-14 审计缺陷 3 已修）。
- **垫系**：原点 = 格心，x = page +x，y = page −y；垫位姿**每轮现解**
  （`grid-pre.json`，10 帧），计划与判分读同一份，不沿用不比对（2026-11-04 拍板）。
- **区常量单源**：拾取区 = `stage4_clear_model.cm.PICK_ZONE`（C2 单源；
  `precision_round.PATROL_ZONE` 是**巡检位**的另一个区，名字勿混——2026-11-14
  审计缺陷 9 的教训）；场景区 = `gen_scene.ZONE` 唯一出处。
