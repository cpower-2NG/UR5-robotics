## 1. 任务场景

用户用**结构化命令**指定杂乱堆里的一块，系统在**接触 / 重叠**的块堆中定位到**同一个实例**，
选一个可执行的 6-DoF 位姿抓出，放到 3×3 宫格的指定格；S3/S4 还要求系统**自己移开遮挡块**，
最终全桌块都在合法终态。

- **指定通道（核心）**：`<color> <position>`（`red left|right|front|back|center`）、
  `<color> <relation> <color>`（`red left-of green`、`yellow on blue`）、`<color> top|bottom`、
  `at <x_mm>,<y_mm>` 或像素点击；可选 `nearest|largest|most_visible`。
  自由语言**后置**，不属于本阶段。
- **指定输出**：实例 ID + 颜色 + base 系中心 / 顶高 / yaw / 可见比例 / 置信度，**回显并允许人确认**。
- **块**：同一批 **29.5 mm 方块**，七色；拾取区沿用 `[0.25, 0.575, 0.17, 0.42] m`（base 系）。
  S3/S4 允许块间**接触 / 重叠**，**不再用 60 mm 最小间距**作规划前置。
- **场景批次**：

  | 批次 | 内容 | 块数 | 出口 |
  |---|---|---:|---|
  | S0 | 隔离基线（主组固定布局库） | 5 | **硬出口** |
  | S1 | 异色接触 | 6 | **硬出口** |
  | S2 | 同色接触 | 6 | **硬出口** |
  | S3 | 两层重叠 | 7 | 进阶 |
  | S4 | 自由布局 + 压遮 | 9 | 进阶 |

  S0–S3 每批 **5 个固定布局**（块心 / 颜色 / yaw / 层号入库，JSON 不含身份信息），
  真机抽 **3 个布局 × 2 次**；S4 自由布局，真机每轮人摆。
- **判分**：指定实例是否抓对、是否抓出、是否放到指定格、全桌终态是否合法、
  过程有无碰撞 / 掉落 / 人工干预。**S0 / S1 / S2 分开报**，不合并成一个「S0–S2 总成功率」。

## 2. 与阶段 3 的技术与设备差异

| 维度 | 阶段 3 | 阶段 4 |
|---|---|---|
| 感知 | 顶面栅格 + 高度掩码 + 4 连通（同高接触块会**合并**） | **多线索实例分割**（3D 聚类 / 顶面矩形 / 凹角与分水岭 / 颜色 / 尺寸先验） |
| 抓取 | 固定俯视 `Rz(yaw)·Rx(180°)` | **6-DoF 候选池**（GraspNet / RNGNet / 几何兜底）+ 统一过滤选择 |
| 规划 | 内部几何检查 + 60 mm 护栏 | **MoveIt 场景对象 + attach/detach**；接触场景关 60 mm 护栏、换 2–3 mm 余量 |
| 相机 | 腕部单路 | 腕部 + **固定俯视第二路**（独立 namespace / TF：`base_link → topcam_link`） |
| 目标 | 格心（自动选块） | **人指定实例**；关系 / 遮挡图 + 结构化谓词 |
| 测量 | 逐层顶面 | 多视角融合 + 俯视抓前对中 + 抓后偏心 |
| 接缝 | SSH + 文件 | 同左（DDS 通了才升级，文件接缝**保留为回退**） |
| 不变 | AG-95、UR5、垫与 `grid.json`、执行三闸、单一投影点、逐次授权 | 同左 |

**关键技术事实**（决定设计，不许在实现里绕开）：

- 现有感知的颜色只用于**分量之后分类**，**不能用来分裂**同高接触块；同色接触（S2）
  必须靠几何 + 尺寸先验。
- 腕部相机**看不见夹着的块**（2026-10-26 实测）⇒ 抓后偏心 `e` 只能用**俯视**量，
  「抓完用腕部拍一帧验证」这类设计直接不做。
- 俯视外参**无声过期**（实测一天漂 0.945°）；「昨天标过」不构成今天的证据。
  俯视深度稳定读远 ~1.9%，是相机属性不是漂移 ⇒ 闸门比**外参 / 相对量**，不比绝对高度。
- 四条边分开：① `base`↔`base_link` 180°；② `tool0`↔`camera_link` 手眼；
  ③ `camera_link`↔`optical`（D435i 实测 15 mm）；④ 俯视固定外参（垫 PnP）。
  15 mm **不是**手眼偏置，`STAGE3_CAMERA_OFFSET` **不是** link→optical。
- 认相机只认**外壳标签的 SDK 号**；两路相机的参数文件 `serial_no` 必须不同——
  相同 ⇒ 两个节点抢同一台相机，联合标定会变成「自己跟自己比」的 0 mm 假绿。
- 同一 TF 树只允许**一个** `camera_link` 父节点；腕部手眼 TF 由板上独立脚本发布，
  俯视只准用 `topcam_link`，真机 launch 必须 `publish_camera_tf:=false`。

**本阶段的入口次序（用户 2026-11-07 决定）**：E3a → E2 → E3b → E4a 是一条硬链，
任何一环红就停在那环；E4a 可整体顺延，**不降判据**。

### 3.1 E3a / E3b 的分工（不许混）

- `topcam_drift_check.py` 是**探测器**，只有两种结论：**1 = 看见了变化**（外参作废）、
  **2 = 看不清**（证据不足 / 环境不满足）。**它不再返回 0。**
- 「外参是否仍有效」**只能**由 E3b 的垫/板 PnP 直接解一次回答；
  光流静止 **不是** 通过的理由（相机静止与亚 2 px 漂移在像里不可分）。
- E3b 每轮次序固定：drift 筛查（1 或 2 都进 PnP，**都不放行旧值**）→ 垫 PnP `--solve` →
  与存盘外参比（>1 mm / >0.2° ⇒ 重解）→ 重解仍超 ⇒ **停车** → 新外参端到端复核
  （两路垫 PnP ≤2 mm / ≤0.5°）。第 1 轮没有「上次的图」时明确记「无法 drift，只凭 PnP」，
  **记录在案，不假装做过**。

### 3.2 E4a 的取消条件

悬停位可见性不达标时先**换悬停位**（水平偏移 / 高度），仍不达标 ⇒ 按主计划书
「**取消该功能**」，写进台账与本契约悬案，**不硬凑**、不降低可见比例与精度阈值。

## 4. 出口判据

### 4.1 主命题

**在接触 / 重叠的杂乱堆中，用「颜色 + 方位 / 关系」把用户指定的那一块定位为同一个实例，
并在碰撞约束下抓出、放到指定格**；S0–S2 能达到硬出口，S3/S4 报告能做到什么程度。

- 分析单位 = **块级尝试**（一个指定块的一次完整抓放；含移遮挡，只对指定块计一次）。
- 分母 = 该轮**全部指定块**，不剔除失败块。
- **void**（外部原因未完成）不计入分母但记录原因；同一判据连续 3 次 void ⇒ 停。
- **fail**（系统原因）计入分母，算失败。
- 失败必须**分类**（感知 / 候选 / IK / 规划 / 执行 / 放置 / 人为），不能只报「失败」。

### 4.2 测量协议

1. **`rc=0` 不算成功**：抓取成功 = 指定块被抓出、抬到验证位、未掉、未抓错，
   由**俯视 + 腕部 + 人眼**三方确认。
2. **放置格**由垫 PnP + 人眼确认（不压线、不越界）。
3. **终态**测全桌：所有块在合法格 / 自由区，不重叠、不落地、不越界。
4. **人眼复核**：未填复核意见 ⇒ 不得判 `ok`。
5. 测量来源不得复用控制感知：判分走独立测量链（E13）。
6. 俯视闸门**每轮**跑，通过后才允许该轮使用该外参；`site.yaml` 只做启动参数落盘副本，
   **门输出才是事实源**。

### 4.3 S0–S2 硬出口判据

| 判据 | 定义 | 通过 | 不过时动作 |
|---|---|---|---|
| 指定 ID 正确率 | 系统选中的实例 = 真值指定实例 | ≥90% | 停，查分割 / 解析 |
| 抓取成功率 | 指定块被抓出、抬到验证位、未掉、未抓错 | ≥80% | 停，查候选 / 执行 |
| 放置格成功率 | 指定块落在指定格内（不压线、不越界） | ≥90% | 停，查放置 |
| 全桌合法终态率 | 所有块在合法格 / 自由区，不重叠、不落地、不越界 | ≥90% | 停，查移遮挡 / 复位 |
| 安全事件 | 碰撞、掉落、非预期运动、急停 | **0** | 立即停轮 |
| 人工干预 | 除授权 / 摆场景 / 确认外的动作 | **0** | 该轮按原因记 void / fail |
| 自主 top-1 | 不追问直接选中 | 单独报，**不设硬门** | 能力指标，不混入 0 干预 |

**前置**：E0–E8（M1/M2 硬门）全过；相关支撑门全过；每轮俯视漂移闸门通过；
抓前对中 / 偏心补偿生效；attach/detach 无错误。

### 4.4 轮次与达标

- S0–S2：真机每批 **3 个布局 × 2 次**；出口取**连续 3 轮**，中间不得改阈值 / 改代码
  （插入则重新计数）。
- S3/S4：先跑基线（仿真 5 布局×3、真机 3 布局×2），报告成功率与失败分类，
  **阈值由用户看完数据后拍板**，本契约不预设硬门。
- 同一布局重复 = 重复性；跨布局 = 泛化；两者分开报。
- 配对比较（McNemar）只在 discordant pairs ≥6 时有判别力，不足只报描述统计。
- **阈值变更**须用户显式授权、记录原因与生效轮次；变更前的轮不计入「最后 3 轮」。

### 4.5 判分与归档

- 判分本体 = `scripts/stage4_score.py`（照阶段 2/3 先例：逻辑在代码，断言由测试把守），
  退出码 **0 = 全过 / 1 = 有不过或待人评 / 2 = 数据缺失或坏**。
- 每轮归档（仓外 `runs/`）：`round.json`、`score.json`、`score.md`、标注图 / 视频；
  **失败帧保留**。
- 阶段收束另出 `技术报告.md`（冻结）。

### 4.6 安全与人工干预（每轮）

- **真机每轮一次授权**，覆盖该轮完整计划（含 S4 多步移遮挡）：展示计划（目标实例 /
  抓取序列 / 放置格 / 预计时长）→ 人做 **STOP → PLAY 两步握手** → 执行。
- 授权方式是**对控制器状态的两步只读核验**（Dashboard 29999 只读），两步都看到才发令牌；
  令牌短时有效，**上一次不覆盖这一次**，**授权不来自数据**（任务描述 / 环境变量 / 记忆都不算）。
- 轮内任何偏离（重规划、重试、换目标）⇒ 停，重新授权。
- 夹爪写寄存器（初始化 / 开合）另走 AGENTS **红线 2 的当次授权**（急停就绪、
  两指整个行程内无手无遮挡）；初始化状态只读 `0x0200`。
- 任何碰撞 / 掉落 / 指定块丢失 / 夹爪未初始化 / 程序自停 ⇒ **停轮，不自动续跑**。

## 5. 明确不做

- 自由语言解析（结构化语法为核心，NL 后置）；学习式实例分割训练（S2 不够再单独立项）。
- 非方块 / 任意物体（阶段 5）、多块同抓、动态目标、传送带。
- 把仿真成功当阶段出口（仿真只做预验证）。
- 无限次抓前对中闭环（≤2 次修正）；把偏心补偿与放置偏置 `b̂` 混为一个量。
- 在真机上做未经当次授权的运动 / 夹爪写寄存器。
- 拿俯视绝对深度当高度判据（深度的 ~1.9% 偏差是相机属性）。
- 「抓完用腕部拍一帧验证」（腕部看不见夹着的块）。

## 6. 失败模式表

| 失败模式 | 现有缓解 | 阶段 4 处置 |
|---|---|---|
| 接触同高块合并 | 4 mm 栅格 + 4 连通 | 多线索分割；S2 单独验；仍不可分 ⇒ 人确认 / fail-closed |
| 同色块颜色掩码合并 | HSV 投票 | 几何为主、颜色为辅；尺寸 / 矩形先验 |
| 指定歧义 / 多匹配 | 无 | 谓词 + 排序 + 置信度差；0 匹配不猜；差距小要求人确认 |
| GraspNet 分数不可信 | 只作准入 | 分数只过阈值；排序用碰撞 / IK / 夹持 / 对中 |
| 全姿态 IK 坏分支 / 奇异 | 整链选支 | 接近方向一致性 + 奇异检查；无解即停 |
| MoveIt 场景缺失 / 假碰撞 | 只有桌子 | 逐块 OBB + 夹爪几何 + attach/detach；M1 先验 |
| 60 mm 护栏拒绝接触 | 硬编码 | 接触批次关闭，换 MoveIt 碰撞 + 2–3 mm 余量 |
| 俯视外参过期 | 无（无声） | 每轮 E3b 门；>1 mm/0.2° 重解；重解仍超停车 |
| 俯视被夹爪 / 臂挡 | 未知 | E4a 悬停位可见性；不达标换位或取消该功能 |
| 双相机序列号相同 | 无 | launch 当场抛错（两文件 `serial_no` 必须不同） |
| `camera_link` 双父节点 | 无 | 真机强制 `publish_camera_tf:=false`；俯视只用 `topcam_link` |
| 程序自停 / 反向接口断开 | 执行器 fail-closed | 停轮、人工判读；不自动续跑 |
| 板载算力不够 | 未验 | 网跑本机 + 文件接缝；失败即降级，不改判据 |

## 7. 悬案

1. **同色接触分割（S2）纯几何够不够** —— E5 回答；不够是否允许轻量学习分割，单独立项。
2. **AG-95 仿真代理** —— 建简化 AG-95，还是 Robotiq 2F-85 代理并明确折扣？E1 前拍板。
3. **单俯视能否同时覆盖整垫 / 拾取区 / 宫格 / 悬停位而不被挡** —— E2 / E4a 回答；
   不能则改支架 / 加第二俯视 / 接受部分位置降级。
4. **S3/S4 阈值** —— 基线后由用户拍板；在此之前只报告，不硬判。
5. **板载算力** —— GraspNet / RNGNet 在板上的延迟 / 显存；不够则本机跑网 + 文件接缝。
6. **跨机 DDS** —— 板↔本机 L3 未通即走纯本地回退；不以 DDS 为阶段出口前提。
7. **仿真↔真机差距** —— 接触摩擦 / 深度噪声 / 颜色光照；用一致性验证量化，
   不用仿真成功率替代真机结论。
8. **场景复位人力** —— S3/S4 每轮人摆，现场时间可能是瓶颈；每轮块数与试验数要有上限。
