## 2. E2 俯视第二路 + 双相机联合标定

**判据**：覆盖整桌 + 宫格 + 悬停位；**两路垫心 ≤2 mm、yaw ≤0.5°；连续 5 轮**；
每轮腕部 + 俯视各一帧、RMS ≤1.5 px、每页垫 ≥4 标记。

**做法**：
1. 俯视只发 `base_link → topcam_link`（独立 namespace / `camera_name: topcam`）；
   真机 `publish_camera_tf:=false`（腕部手眼 TF 另有独立发布者，不得出现第二个
   `camera_link` 父节点）。
2. 腕部帧 → `stage2_pad.solve_pad` 得 `base←pad`；俯视帧 → 同一 `solve_pad` 传单位外参
   得 `topcam←pad`；联立 `base←topcam = base←pad ∘ (topcam←pad)⁻¹`。
3. `base←topcam_optical` 用**驱动实测** `topcam_link→topcam_color_optical_frame` 链换算，
   不用理想 link→optical。
4. 第 1 轮解出的外参**才**用来重启发布 TF；不拿旧外参反喂。

**工具**：`real.launch.py`（topcam 参数 / 守卫 / 节点 / TF）、
`precision_capture.py --camera topcam --burst`、`stage2_pad.py --cam-identity`、
`topcam_marker_calib.py --out/--tf-json`、新 `stage4_joint_calib.py`。

**5 轮位姿**：从 `SURVEY_TOOL0["stage2high"]` (0.452, −0.200, 0.547) 出发，
用 `stage3_survey_tool0` 在 ±30–50 mm 内取 5 个横向偏置，保证垫始终在腕部视场内。

**状态**：代码就绪后上真机；任一轮红 ⇒ 不通过，先查布场 / 相机绑定，不带病进 E3b。

## 3. E3b 垫 PnP 外参门（每轮）

**判据**：每轮都有 drift + PnP + 联合标定增量；>1 mm 或 >0.2° 必重解；重解仍超
**停车**；5 轮无一次静默放行旧值。

**每轮固定次序**（契约 §3.1）：
1. `topcam_drift_check --old <上次标定的图> --new <刚拍的图>`：1 ⇒ 进 2；2 ⇒ **也进 2**；
   不可能出现 0。第 1 轮无参考图 ⇒ 明确记「无法 drift，只凭 PnP」。
2. `topcam_marker_calib --solve --image … --info … --tf-json … --out …`：
   检测失败 / RMS 超限 ⇒ 退出 2，停车。
3. 与存盘外参比：>1 mm / >0.2° ⇒ 重解（重拍一帧再 `--solve`）；仍超 ⇒ 退出 1，停车。
4. 新外参跑 E2 的两路垫 PnP 端到端复核（≤2 mm / ≤0.5°）。
5. 通过才允许后续使用；落盘 `extrinsic-gate/round-NN.json`
   （drift 结论、旧/新差、是否重解、端到端 Δ、时间）。

**工具**：新 `scripts/topcam_extrinsic_gate.py`、`scripts/topcam_marker_calib.py`。

**状态**：代码就绪后上真机。

## 4. E4a 悬停位可见性

**判据**：悬停 **50 / 65 / 80 mm**；每高度 **≥20 帧**；可用比例 **≥60%**；
可用帧中心 `center_span_mm/2 ≤2 mm`、`yaw_span_deg ≤2°`。

**几何**：`tool0_z = 块顶 z + TOOL0_TO_BARE_FINGERTIP(0.2042) + hover`——
**不能用** `TOOL0_TO_FINGERTIP(0.1757)`（那是块高折扣后的抓取点）。

**做法**：块位置先由俯视给（用 E2 解出的外参 + `stage3_measure.measure_frame(frame=…)`），
再把 tool0 摆到块心正上方；每个高度 `precision_capture --camera wrist --burst 20`，
臂静止；逐帧量，`usable` 帧才进融合。

**不达标**：先换悬停位（水平偏移 / 高度）；仍不达标 ⇒ **取消该功能**，
写进台账与契约悬案，不硬凑。

**工具**：新 `scripts/stage4_hover_check.py`、`scripts/precision_capture.py --burst`、
`scripts/stage3_measure.py`。

**状态**：代码就绪后上真机。

## 5. 真机运动授权（E2 / E4a 的前置）

- 新 `scripts/real_motion_authorize.py`（板端，**只读** 29999），拆成两次可阻塞调用：
  - `--step stop`：等 **STOPPED**；看不到 ⇒ 退出 2。

    两步都成立才写令牌。
  - 任何查询失败 ⇒ 不写，fail-closed；脚本**从不**发送 play/stop。

  上一次授权不覆盖下一次；授权只来自这两次现场观测，**不来自数据**。
