## 1. 阶段梯子

阶段按**任务场景的变化**划分，不按工作项划分。每一级钉死一个**核心能力**；
3–5 级只写提议要点，**进入该级时与用户逐项讨论后写契约**。

| 阶段 | 任务场景 | 考验的核心能力 | 状态 |
|---|---|---|---|
| **1 · 点对点抓放** | 单个或少量方块的点到点抓放 | 链路贯通、基础抓放 | ✅ 2026-10-05 出口；A3 精密抓放为其能力增补，2026-10-26 收束（[`阶段1-点对点抓放/A3精密抓放-实验记录.md`](阶段1-点对点抓放/A3精密抓放-实验记录.md)） |
| **2 · 宫格归位** | 乱摆 ≥5 块（任意 yaw、颜色混放）→ 抓放进 3×3 宫格**按颜色归位**，边缘对齐格线 | 姿态估计（yaw）＋颜色识别＋精准放置 | 🔵 现行——契约见 [`阶段2-宫格归位/契约.md`](阶段2-宫格归位/契约.md) |
| 3 · 堆叠 | 3 块直塔起步 → 达标挑战 5 块；xy±5mm / yaw±5° / 释放控制 | 放置精度与释放控制；eye-in-hand 精修**条件触发**（阶段 2 误差分解显示感知占主导才做） | 提议——进入时逐项讨论 |
| 4 · 杂乱指定抓取 | 用户/agent 指定某块（颜色+方位描述或点击）→ 在接触/重叠堆中定位并抓出、放到指定处 | 杂乱感知、抓取候选选择、指定交互——**GraspNet 升为主线**（几何顶面拟合在接触/遮挡下失效） | 提议——进入时逐项讨论 |
| 5 · 非方块 | 日常物件（物体集到时定）抓起 + 入箱 | 物体无关抓取（GraspNet 类方法的主场） | 提议——进入时逐项讨论 |

> **原「阶段 2 · 多类分拣」的处置**（2026-10-26）：按用户拍板不再作为独立阶段
> （「类别与泛化不做」）；其颜色识别能力以**受限形式（七色对七格）**纳入现阶段 2。
> A2 线的工具链先例在 tag `archive/b1a-place-view`，七类权重外链见 README「模型权重」。

## 2. 每个阶段进入时要写一份契约

`docs/阶段/阶段N-<场景>/契约.md`，**七项**：
任务场景 / 与上一阶段的技术与设备差异 / 入口判据 / **出口判据** / 明确不做 /
**失败模式表**（每行：失败模式 → 现有缓解 → 处置）/ 悬案。

**出口判据要写成可执行的**（照 `scripts/board_a1.py` 的判分先例）——
写不出可执行判据的项，不算出口。
契约**只写判据与边界**：不写执行步骤（执行方以契约为准自行规划），不写现状（→ [`../当前状态.md`](../当前状态.md)）。
