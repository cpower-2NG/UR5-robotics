## 1. 任务场景

用户把 ≥5 块积木**乱摆**在拾取区（任意 yaw——与基准方向差 >15°，颜色混放）；
系统逐块**识别颜色与位姿** → 抓取 → 放进基准垫 3×3 宫格中**对应颜色的格**；
终态所有已放置块**边缘平行于格线、居中**。

- **基准垫**：两张 A4 横向拼贴（各印 ChArUco 标记；**拼贴关系由视觉识别**，
  不假设两张物理对齐）。垫上印 3×3 宫格：格心距 55–60 mm、格内印色标，
  7 色各占一格、2 格备用。PDF 由脚本生成；打印、拼贴、粘贴由用户完成。
- **判分（三方冗余）**：
  1. **腕部多姿态自测**——终态从 ≥2 个 survey 位姿各抓一帧；跨姿态一致性
     yaw ≤3° 且位置 ≤3 mm 才算机判有效，否则该块标「待人评」；
  2. **判分标注图人眼评**——yaw 箭头 / 格内偏移 / 色格对错直接画在图上；
  3. **用户直接看台面**——印刷格让人眼一眼可判。
- 不涉及：抓取顺序优化、多块同抓、动态目标。

## 2. 与阶段 1 的技术与设备差异

- **yaw 进控制回路**（阶段 1 固定 ψ=0）；
- **颜色归位决策进主链路**——七类模型（`block_best_7cls.pt`，2026-10-05 训练，
  外链见 README「模型权重」）首次正式使用。⚠️ 它在**腕部相机域从未验证过**
  （A3 实测腕部帧基本检不出）——这是本阶段最大的技术风险；判分把「色格正确」
  单列，检不出/误识不与姿态误差混算；
- **AG-95 指轴标定**（新前置实验，见 §3①——「块的 yaw」换算成「腕部转角」的钥匙）；
- 判分协议（多姿态自测）与离线渲染管线（MP4）；
- 基准垫视觉定位（ChArUco → 垫系）；
- 设备不变（腕部 D435i / AG-95 / UR5）。**俯视相机不回系统**
  （2026-10-26 拍板：漂移不可控，真值改腕部多姿态自测 + 人眼）。

## 3. 入口判据（全部满足才开工真机循环）

| # | 判据 | 怎么算成立 |
|---|---|---|
| 1 | **指轴标定** | 3 个已知 yaw（相互 ≥30° 分布）的块：survey 测 θ_face → 执行 ψ=−θ_face 抓放 → 终态边缘与格线差 ≤3°/块（三块全对 = 指轴→腕角映射线性且零偏正确） |
| 2 | **几何 yaw 重复性** | 现有 runs 乱摆帧上同一块跨 ≥3 帧，yaw（mod 90°）极差 ≤6°（纯离线，不动臂） |
| 3 | **渲染器管线通** | 任一历史 run 出第一支 MP4（点云 + 机械臂轨迹 + 候选/执行抓取位姿） |
| 4 | **基准垫就位** | 拼垫 PDF 生成、打印、拼贴贴好；腕部帧能同时看到两页标记并解出垫系 |

## 4. 出口判据（可执行；数值阈值首轮基线后拍板）

- **判分本体 = 自动判分脚本**（照 `scripts/board_a1.py` 先例：判分逻辑在代码、
  断言由测试把守）。逐块三项：**色格正确**（二值）/ **yaw 误差**（对格线，mod 90°）/
  **格内位置误差**（块心到格心距离）。
- **阈值**：首轮基线轮跑完由用户拍板；起点建议 yaw ≤8°、格内位置 ≤12 mm、色格全对。
- **轮次**：≥3 轮达标。
- **三臂对照（全执行）**：每轮内块轮流分配给「几何 yaw 臂 / ψ=0 基线臂 /
  GraspNet 角臂」，每臂累计 ≥6 块，报告按臂分列——用**执行级**数据回答
  「姿态估计值多少分」（离线对账不算数）。
- **归档**：每轮 MP4 + 判分图 + round.json 落仓外 `runs/`。

## 5. 明确不做

堆叠 / 杂乱指定抓取 / 非方块（阶段 3–5）；roll/pitch 全 6DoF（只做 yaw，mod 90°）；
GraspNet 候选宽当开口命令；实时可视化（只做离线 MP4）；俯视相机回系统；
完整多类分拣（任意类别任意布局——本阶段只做「七色对七格」的受限形式）。

## 6. 失败模式表

| 失败模式 | 现有缓解 | 处置 |
|---|---|---|
| 颜色误识 → 入错格 | 七类模型 + HSV 投票双源；⚠️ 腕部域未验证 | 判分单列「色格正确」；误识率高 ⇒ 立项（补采腕部数据集微调） |
| 姿态估计错 → 放歪 | 跨姿态一致性闸（≤3°）；mod 90° 显式处理 | 闸不过的块标「待人评」，不混入统计 |
| 指垫间滑移 → 终态偏 | 抓后/抬升回读判「没滑」（角度滑测不了） | 终态 yaw 首次可测 ⇒ 本阶段量化「夹持后转不转」（关旧悬案） |
| 乱摆间距 <60 mm → 抓取干涉 | 摆件要求（间距 ≥60 mm）+ 视野闸门 | 现场乱摆仍须保持间距 |
| 光照不足 → 颜色全 unknown | 光照闸门（p99 ≥ 60） | 已有；开顶灯 |
| 无候选 / 跳块 | A3 已有跳块重巡检 | 沿用 |

## 7. 悬案

- 近方形顶面（长短差 <4 mm）的 **yaw 边缘选择歧义**——对 90° 周期对齐无害，
  但估计器需显式 mod-90 与确定性选边规则；
- **夹持后块在指垫间转不转**——阶段 2 终态首次可测，测完关案。
