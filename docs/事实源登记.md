# 事实源登记（**一个事实一个家**）

> **层级**：恒久 · 这份只回答一句话：**某个会变的事实，该信谁？**
>
> 规矩：每个事实**只有一个家**，别处提到它**只准指路，不准复述**（本仓栽过，见 §3）。
> ⚠️ 这张表只登记「路由」，不登记「值」 —— 在这里写下数字，它自己就变成第二个家。

---

## 1. 两条判据

1. **写下一个会变的值之前，先查这里。** 表里有家 → 只写链接，不写值。
   表里没有 → 先想清楚它该住哪层（判据见 [`文档地图.md`](文档地图.md) §1），**然后登记进来**。
2. **矛盾的定义**：两个家同时主张同一个「现在」为真。流水里「曾测出 X、后判为假」不是矛盾，那是历史。
   **状态层是「原地覆写」，不是「追加」** —— 新结果推翻旧结论时，`当前状态.md` 那一行直接改掉。

## 3. 本仓栽过的三起（都是「复述」，不是「说错」）

| 形状 | 两处打架在哪 | 处置 |
|---|---|---|
| 恒久层复述状态层的事实（README 说某包「还缺」，同文件前文与参考文档都说已装） | README 内部 + 跨文件 | 改成指向 `当前状态.md` |
| 同一几何量在状态层和参考文档各写一个值 | 跨层 | 以状态层为准；参考文档那份改指路 |
| **同一份状态文件内部**自相矛盾（靠前说验收通过，靠后记着每轮失败） | 同文件内 | ⚠️ 2026-10-26 重写 `当前状态.md` 时已清 |

## 4. 这张表现在没有机器把守

**下次再出现「同一个事实两个家」，就给 §2 配脚本**（白名单扫重复值，误报逐条写理由）。在那之前它靠自觉，会漂。
