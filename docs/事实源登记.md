# 事实源登记（**一个事实一个家**）

> **层级**：恒久 · 这份只回答一句话：**某个会变的事实，该信谁？**
>
> **规矩**：每个事实**只有一个家**。别处提到它时**只准指路，不准复述**。
> 复述过一次就有了两个家，两个家迟早说不一样的话 —— 本仓已经栽过（见 §3）。
>
> ⚠️ **这张表只登记「路由」，不登记「值」。** 一旦在这里写下某个数字，
> 它自己就变成第二个家，这张表也就成了它要治的病。

---

## 1. 两条判据

1. **写下一个会变的值之前，先查这里。** 表里有家 → 只写链接，不写值。
   表里没有 → 先想清楚它该住哪一层（判据见 [`文档地图.md`](文档地图.md) §1），
   **然后把它登记进来** —— 没登记的事实，下一个会话就会在别处再写一遍。
2. **矛盾的定义**：**两个家同时主张同一个「现在」为真。**
   流水里「曾测出 X、后判为假」**不是**矛盾，那是历史 —— 而且正是它该待的地方。

> **状态层是「原地覆写」，不是「追加」。** 新结果推翻旧结论时，`当前状态.md`
> 那一行**直接改掉**；于是文档里永远只有一个值，不存在"新旧并存"。

## 3. 本仓栽过的三起（**都是"复述"，不是"说错"**）

写在这里是为了让人认出**形状**，所以刻意不复述具体数值：

| 形状 | 两处打架在哪 | 现在怎么处置的 |
|---|---|---|
| 恒久层复述了状态层的事实：README 末尾说某个 Python 包"还缺"，而**同一份 README 的前面**和 `机械臂系统参考.md` 都写着已装 | README 内部 + 跨文件 | 2026-10-08 改成指向 `当前状态.md` |
| 同一个几何量在状态层和参考文档里各写一个值（相机高度），差了一截 | 跨层 | 以状态层为准；参考文档那份应改为指路 |
| **同一份状态文件内部**自相矛盾：靠前几行说某项验收通过，靠后又记着这项每轮都失败 | 同文件内 | ⚠️ **尚未修** —— 这正是"反复测试"留下的典型残骸 |

> **第三起值得记住**：它不是"两份文档不同步"，而是**结论被推翻后，旧结论没被改掉**。
> 反复测试必然产生这个过程；**伤害只在旧结论还留着"现在"的语气时**发生。

## 4. 这张表现在**没有机器把守**

按约定先跑一段（决定见 2026-10-08 的讨论）。也就是说：**它靠自觉，会漂。**

判断它有没有用的信号很具体：**下次再出现"同一个事实两个家"，就是它没拦住 —— 那时该给它配脚本了。**
配法（先记在这，别提前做）：把 §2 的"家"当白名单，扫常驻文档里出现的版本串/比例/毫米数，
同一串命中两份不同的家就报警；误报按本仓老规矩**逐条写进白名单并写明理由**
（先例见 [`文档地图.md`](文档地图.md) §6 与 `scripts/test_deidentified.py`）。
