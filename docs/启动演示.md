## 1. 开跑前，只确认三件事

| # | 确认 | 判据 |
|---|---|---|
| 1 | 板子上那条 ROS 栈起着 | 板上 `pgrep -cf dashboard_client` → **1**（0 = 没起，照 runbook 第二、三步起；>1 = 有孤儿，先拆栈） |
| 2 | 示教器程序 `PLAYING` | 示教器上看到 **PLAYING**；不是就先按 PLAY |
| 3 | 夹爪已初始化 | 脚本会读 `0x0200`；**不是 1 它会停下来把命令打给你**——初始化是另一次授权（急停就绪 + 两指整个行程内无手无遮挡），脚本不代跑 |

台面：塔位立着也没关系——机器人会**先自己逐层拆回拾取区**，不需要人拆。
**块心必须落在拾取区 x 250–575 mm、y 170–420 mm（base 系）内**，整块都进去、
离边界留 ≥20 mm 更稳——贴边的块会被判红，不会被抓。
摆好人退开、手离开台面。

## 2. 一条命令

```bash
cd ~/robotics/worktrees/ur5-vision-grasp/stage3
bash scripts/demo_stage3.sh
```

| 想怎样 | 加什么 |
|---|---|
| 更快（每视点少抓一帧，测量噪声略大） | `--frames 2` |
| 只生成计划、不连板不动臂 | `--dry-run` |
| 判分通过后**保留塔**（留现场看；默认会拆回拾取区） | `--keep-tower` |
| 换 SSH 别名 / 层数 / 输出目录 | `--board <别名>` / `--n-layers 2` / `--run-dir <目录>` |

## 3. 它会问你什么

- **动臂前一次 `yes`**（红线 6）。stdin 不是交互终端就直接拒绝、零动作——
  所以别用 `nohup`、别重定向、别塞管道。
- 万一只读预检里 `PLAYING` 掉了，它会让你去示教器按 PLAY，回车重试（最多 3 次）。
- 判分停在 `person_review` 时，它会让你**先看塔**，再决定要不要敲 `yes` 记人工复核。

## 4. 成了没有

最后一行 `结论：verdict=ok`、退出码 0 ⇒ 通过。其它都是没过：

| 结尾 | 含义 | 先看哪 |
|---|---|---|
| `verdict=ok` | 这次演示达标 | — |
| `verdict=person_review` | 机器判不了，要人眼看塔 | 上一步会让你决定 |
| `verdict=fail` / 非 0 | 没过 | `<轮次目录>/round-*/score.json` |
| 中途 `!!` 退出 | 停在那一刻，**不续跑** | `!!` 那行 + `demo.log` |

**任何一步判红都立刻停**，不重试、不接着跑下一层。臂停在原地，块可能还在爪里
或只放了一半——先看示教器。

> `--dry-run` 的退出码 0 只表示**计划生成成功**，不判分、不动臂。

判分通过（`verdict=ok`）后，脚本会自动**拆塔回拾取区**，台面还原；
`person_review` 未核准或 `verdict=fail` ⇒ **不拆**，塔留在原地给人看。
拆塔失败也会明确报 `拆塔没走完`，不会假装收工。

## 5. 产物在哪

默认 `~/robotics/notes/ur5-vision-grasp/runs/<日期>-stage3-demo/`
（`--dry-run` 加 `-dryrun` 后缀）：

- `demo.log` —— 完整终端回显（同样的内容也打在屏幕上）
- `pad-frame/` —— 垫位抓帧
- `grid-demo.json` —— 重解出的垫位
- `round-NN/` —— 每轮的计划、执行日志、`score.json`
- `teardown-after/` —— 判分后的拆塔记录（拆了几层、塔位是否已空）

## 附：它内部串了什么（排查用，平时不用看）

只读预检（`robot_mode=7` / `safety_mode=1` / `PLAYING` / JTC action + 控制器 active /
`dashboard_client` 恰好 1 / 夹爪 `0x0200=1`）→ 走到 `stage2high` 抓垫位帧 →
`stage2_pad.py` 重解垫位 → `stage3_round.py --go` 跑 N 层 → 判分。

参数集就是六轮验收用的那一套（`--group open --arm geometric --place-target previous
--bias-comp fixed ...`），**不需要手改**；确实要改看
`scripts/demo_stage3.py` 的 `round_argv()`。
逻辑自检：`python3 scripts/test_demo_stage3.py`。
